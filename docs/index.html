seamless-loop-video

Turn a still into a seamless looping video

Turns a still image into a looping ambient video for a web header or background, using MiniMax H3 in ComfyUI. It covers the settings that actually produce motion (pinning last_frame back to the source stops the model from moving at all), closing the loop with real frames rather than a fade, and measuring whether it worked. Ships make-loop.py, seamless.py and chain.py.

Use when: you want a looping background or hero video, "make this image move", or a generated loop visibly jumps or barely moves.

Install

git clone https://github.com/Violinet-tech/seamless-loop-video ~/.claude/skills/seamless-loop-video
